📖 第一次設定步驟（LINE Developers + Vercel）
  1. 到 LINE Developers 建立 Provider → 建立 Messaging API Channel（這就是員工專用官方帳號）。
  2. Channel 的 Basic settings 複製 Channel secret；Messaging API 分頁最下方發行 Channel access token。
  3. 在這頁按「🔑 產生 Bot 金鑰」，複製金鑰與上方的系統網址。
  4. 到 Vercel 匯入 GitHub 專案，Root Directory 選 linebot；Environment Variables 填： LINE_CHANNEL_SECRET、LINE_CHANNEL_ACCESS_TOKEN、GAS_URL（系統網址）、BOT_SECRET（Bot 金鑰），然後 Deploy。
  5. 回到 LINE Developers 的 Messaging API 分頁：Webhook URL 填 https://你的專案.vercel.app/api/line，打開 Use webhook，按 Verify。
  6. 到 LINE Official Account Manager → 回應設定：關閉「自動回應訊息」與「加入好友的歡迎訊息」（改由機器人回覆）；聊天的「群組」功能建議關閉。
  7. 用手機加官方帳號好友、傳一句話 → 這頁的「待開通」會出現你自己 → 開通後就可以開始問了。
